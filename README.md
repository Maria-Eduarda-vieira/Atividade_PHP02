Nesta atividade de Backend, foi desenvolvido um formulário web interativo utilizando HTML5 para captura de dados e PHP para o processamento e salvamento das informações do usuário diretamente em um arquivo de texto local (log_acessos.txt), assim podendo realizar a verificação se o usuário tem 18 anos ou mais.

-------------------------------------------------
**Ferramentas utilizadas 🛠️:**
-Visual Studio Code
-HTML5 (Estruturação do formulário de cadastro)  
-PHP (Processamento dos dados via POST e manipulação de arquivo .txt)

🎯 Exercícios em PHP

| # | / Atividade | Cadastro do usuário | Tópicos de PHP / Lógica |
| :-: | :--- | :--- | :--- |
| **01** |  **Verificação de idade** |	Se o usuário tiver 18 anos ou mais, ele pode acessar | if / else, Operadores Aritméticos, Manipulação de Arquivos (`fopen`, `fwrite`), Métodos HTTP (`POST`), Funções de Data (`date`) |

----------------------------------------------------------------------------------------------------------------------------------------------------------------
Objetivos🎯:
[x] Criar uma interface HTML acessível com formulário para entrada de dados.
- [x] Capturar requisições enviadas via método `POST`.
- [x] Calcular a idade do usuário dinamicamente com base no ano atual do sistema.
- [x] Gravar o histórico de acessos em um arquivo de texto (`log_acessos.txt`) usando funções de manipulação de arquivos no PHP.
- [x] Validar a maioridade do usuário ($\ge 18$ anos) e retornar um alerta visual no navegador.
